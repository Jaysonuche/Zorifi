NEWLY IMPLEMENTED / REPAIRED
- Gemini image/music 429 errors are sanitized and distinguish zero available
  quota from retryable rate/quota exhaustion. Bounded Retry-After survives the
  real handler; no automatic retry or paid-provider switch. Music errors point
  to native/imported audio rather than irrelevant image tools.
- Background reconstruction UI enforces a source/account/project cooldown.
  Local texture fill is an explicit alternative with source-matte review,
  retained original, cancellation/stale guards and device persistence. It fills
  from neighbouring visible colours, bounded to 640px; it can smear complex
  backgrounds and does not recover hidden objects/text. Import a clean plate
  when fidelity matters. Same reviewed workflow is available to Vanessa.
- Nested composition name/dimensions/duration/fps now have manual controls
  using the existing composition.settings graph opcode also used by Vanessa.
- Root Composition settings validate bounds and restore native state/history
  when device saving fails. Root composition-format automation is not a new
  Vanessa command; supported nested settings share the existing validated tool.
- Frame snapshots use separate decoders so they cannot seek the live preview
  or move the user's playhead. Caches prune deleted layers and release on editor
  exit/account scope changes rather than retaining video buffers indefinitely.
- MP4 startup/duration acceptance is checked before claiming export success.
  Recorder initialization must not consume the requested timeline duration.
- Version 3.47.0, cache 250 and a secret-free public release.json make the deployed
  version/commit inspectable. verify-hosted-release.cjs checks version, commit,
  twelve runtime hashes, authentication rejection and existing AI configuration.

PROVIDER INVESTIGATION / ALTERNATIVES / COSTS
The earlier real clean-plate request returned 429. Gemini rate limits apply to
the project, not to each API key; generating more keys does not raise quota.
The previous response did not prove precisely which account entitlement was
exhausted. The repair uses actual RetryInfo/Retry-After/QuotaFailure details when
available and asks the owner to inspect AI Studio access; it does not assert
that upgrading always fixes every 429.
An existing opt-in OpenAI image adapter is a possible separately billed option,
not a verified free reconstruction service. It was not enabled or silently used.
The implemented local fill and imported clean plate avoid cloud generation
costs. Local fill has no paid model, new binary dependency or external upload.
Existing pinned local person segmentation downloads public runtime/model files
only after explicit consent; source pixels remain on-device.
No new paid AI requests, provider licences, checkout or paid infrastructure were
introduced by this stage. Existing hosting/build/CDN usage remains subject to
the owner's current plan/quotas. The £15 shared AI budget is not a per-user
allowance and is not claimed to be a guaranteed global hard cap.
