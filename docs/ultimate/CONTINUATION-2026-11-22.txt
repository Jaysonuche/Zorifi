PERSISTENT NATIVE SCALE LOCK — PART13
Source patterns now retain a separate enabled/key/scaleMode lock. Enabling or
changing the lock preserves existing notes and their sound. New notes, actual
pitch edits, chord tones and transposition map to the nearest allowed MIDI pitch;
equal-distance ties go lower. Up/down piano-roll keys step to the next allowed
pitch. Timing/velocity-only edits keep an existing chromatic pitch unchanged.
Drum instruments pause mapping without deleting the setting; pitched instruments
resume it. One-shot scale correction remains a separate explicit operation.

Manual controls and reviewed Vanessa music.native.edit commands share the native
worker, source validation, one Undo and on-device persistence. Scope is supported
native instruments/scales, not live MIDI controllers, external plugins or a full
DAW. Existing out-of-scale notes are intentionally not silently normalized. MIDI
export contains real note pitches; editor-lock metadata stays in the project.

REPEATED KEYFRAMED VISUAL ANIMATION — PART25
Typed expression.set {property,expression:{type:'loop',mode:'cycle'|'ping-pong'}}
reuses the first-to-last keyed segment after its end, in that layer's containing
composition clock. The original segment/keys/easing are unchanged. Cycle restarts;
ping-pong reverses then repeats. No key or layer duplication and no JavaScript
evaluation. At least two finite keys spanning1ms are required. Remove the repeat
before deleting required keys. Existing interpolation, nested rates/source trims,
mask/group/effect/repeater channels and render budgets remain authoritative.

Audio gain/pan, source time/rate, spatial-path-owned positions and stagger-owned
textOffset are explicitly excluded. These are visual loops, not audio Live Session
or unrestricted After Effects expressions. Manual selection now loads each chosen
property's own saved repeat mode and Remove availability; changing from X/cycle
to Y/ping-pong cannot silently overwrite Y using X's mode. Shared backend proposal
guidance documents the actual typed schema; native validation remains final.
