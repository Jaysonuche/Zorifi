COVERAGE AND LIMITS

The scanner detects recognizable OpenAI, Anthropic, GitHub, Stripe/payment,
Slack, AWS access-ID, Google API-key and private-key-header shapes. Findings
contain only category, location and a one-way fingerprint; matched content and
source context are never printed. Google API-key matches are review items,
because Firebase public web configuration is not itself an administrator key.

The scanner deliberately does not read .env files, private credential/auth
stores, dependencies, symlinks, binary/zero-byte-containing files or files over
8 MiB. Git history covers reachable objects, not discarded unreachable blobs.
External conversation copies, provider/hosting logs, cloud audit records,
credentials in unrecognized formats and out-of-workspace backups are outside
this scan. No claim of a complete forensic investigation is made.
