NATIVE ADSR — PART8/10/14/16
Each native musicPattern can now carry an optional plain envelope object with
exactly attack,decay,sustain,release. Attack/decay/release are finite0–10 seconds;
sustain is0–1 (the manual control displays0–100%). Native source-note controls
and reviewed Vanessa use the existing music.native.edit operation:
  {edit:{operation:'envelope',envelope:{attack:.01,decay:.15,sustain:.7,release:.08}}}
Reset uses envelope:null and removes the optional pattern field. Repeating the
same envelope or resetting an unconfigured pattern refuses as a no-op.

The actual synthesis worker applies ADSR inside every existing note window.
Attack rises to full level; decay reaches the requested sustain; release fades
to zero on the note's final sample when release is positive. If attack+decay+
release exceeds that note's window, all three times compress by the same factor;
otherwise sustain occupies the remainder. Zero-length stages change instantly.
The instrument's carrier and natural decay remain; no note/source tail, MIDI
timing change or extra voice is added. All seven native instruments are supported.
Patterns without an envelope use the original synthesis arithmetic; independent
WAV comparison across7 instruments and3 supported sample rates matched all21
legacy outputs byte for byte.

Saving renders only the selected native source through the existing worker and
source replacement path, preserving notes, MIDI, clip timing/trims/rate, mixer,
effects, title and source-parent history. Existing locks/scopes/Stop/persistence
guards remain in that path. One save is one Undo. Active native crossfade pairs
must be reset before changing source notes, instruments or envelopes. This is a
bounded native note-volume envelope, not a complete Instrument Lab, LFO/modulation
matrix, wavetable/sample designer, SoundPrint, Sound Fusion or timbre transfer.

Vanessa example:
  Set native ADSR attack 10 ms decay 150 ms sustain 70% release 80 ms
  Reset native ADSR
Seconds are also accepted for attack,decay and release.

EDITABLE PATH MORPH — PART25
The native shape.morph operation stores a version1 channel on motion.pathMorph
or on the selected motion.groups entry's pathMorph. Each key has time,points,
closed and optional easing/bezier; groupId targets an existing named path group.
Manual Motion Scenes controls and the constrained Bezier pen editor share that
operation with reviewed Vanessa motion.edit/dataJson. No generated raster, media
replacement or inferred optical geometry is involved.

Source geometry must already be an editable path. Each key retains the exact
point count, point correspondence/order and open/closed setting. Vertex XY and
relative incoming/outgoing handles interpolate independently; absent handles are
zero. Paint, trim, shape groups, masks and ordinary transform channels remain
separate. A single key holds its path throughout the layer; animation requires
explicit corresponding endpoint keys. Values hold before the first and after
the last key. remove:true with a time deletes one key; without time removes the
channel and restores evaluation of original source vertices.

Key time uses the containing composition clock,0–86400 seconds. Nested source
rates naturally map that clock. Precompose/duplicate and animation.retime shift
or scale main/group keys; source.retime now also scales them around clip.start
when source mode changes duration, alongside scalar/spatial animation. Timeline
duration mode keeps their composition times. Scalar animation.copy deliberately
refuses layers with morph channels rather than omitting or flattening the morph.

Limits:1–128 keys/channel,2–2000 points/key,65,536 keyed vertices/project and the
existing10,000 total animation keys,2,000 layers/24 nesting levels. Coordinates
and tangent components are within±16,384. Local render extent is≤16,384 pixels
and the plane is≤16,777,216 pixels. Handle hulls/strokes/repeaters participate in
local bounds. Review found that individually safe wide/tall keys can create an
unsafe intermediate area; validation now bounds the maximum product over the
whole monotone interpolation segment before committing. It checks non-midpoint
maxima too, while retaining held jumps and safe long-distance path translations.

Supported easing: linear,hold,easy-ease/ease-in-out,ease-in,ease-out and temporal
Bezier with all four handles in0–1. Overshooting curves, topology conversion,
automatic shape matching, optical interpolation and arbitrary expression code
remain unsupported. Full After Effects/plugin/geometry3D/roto parity is not claimed.

SELECTED PROCESSED SAMPLE PEAK — PART20
Normalize selected sample peak replaces the previous hard-coded volume assignment
and LUFS badge. Audio controls, the existing context/pro action and reviewed
Vanessa audio.normalize_peak all call ZorifiSamplePeakNormalize.execute with
{target:clipId,targetDbfs}. The default is−6dBFS; accepted targets are−24 to−1dBFS.
The reviewed bridge authorizes and scopes the ordinary existing proposal path.

One selected unlocked root audio/video source is measured in isolation before
track/master/category levels and other clips. Source trim/rate, source PCM,
EQ/noise/compression/limiter/pan, native level keys and fades feed an actual stereo
offline render. Clip and key gain are after the DSP chain, so scaling that native
envelope does not change its compressor/limiter response. A second render must
reach the requested maximum stereo sample peak within0.05dB before any snapshot
or timeline mutation. The saved edit scales base volume and all volume-key values
by one ratio, preserving key times/easing and all source/timing/FX/mixer fields.

Bounds: selected clip and complete declared source recording≤120s; local original
≤64MiB encoded;128MiB decoded;48MiB stereo output at48kHz. Decoded memory is checked
after native decode, so this is not a guarantee about the native decoder's peak
allocation. Source rate must be constant positive≤16 and remain source-bounded.
Up to1,000 finite unique in-range volume keys use supported monotone native
curves; custom/overshooting curves refuse. Base/key levels stay within0–200%.
Silence, gain beyond200%, failed verification or malformed/unavailable sources
refuse without changing history. Parents/mattes/expressions, nested containers,
remaps/speed keys and muted/locked selected clips refuse. Local File/Blob/data
audio/video originals and supported built-in local sounds are read; remote URLs
are not fetched for this operation.

Account/session/project/view/selection/source/timeline/history guards run around
asynchronous work. Stop/closing/hidden workspace discard late results. Native
decode/render can finish after cancellation; nodes are disconnected and results
cannot commit. Only after both measurements pass is one Undo/save attempted.
Failed device-storage verification restores the prior levels and Undo/Redo and
attempts to persist the restored project. Receipt reports measured before/after
sample peaks and stereo RMS. This is not LUFS, true-peak, full-mix normalization
or full mastering; later mixer gains and overlapping sources can still clip.
