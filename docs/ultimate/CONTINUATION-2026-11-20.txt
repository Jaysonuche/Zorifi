NATIVE HARMONY — PART13
Native Music Studio now inserts separately editable chord tones: nine fixed
qualities, explicit MIDI root, inversion, source start/length and velocity.
Nearest-scale correction applies once to selected notes or the complete source.
Equal-distance pitch ties go lower. Timing, duration, velocity and unrelated
notes stay intact; all-source correction updates the pattern's key/scale label.
Selected-note correction leaves that label unchanged. Source locks, MIDI0–127,
duration, note count and voice budgets are checked atomically before mutation.
The collapsible Harmony controls and reviewed Vanessa commands use the existing
music.native.edit action, native WAV worker and one Undo/save operation.

These are fixed chord insertion and one-shot correction, not persistent scale
locking, chord recognition, AI progression writing, MPE or a complete DAW.
Future note entry is not automatically constrained to the selected scale.

NATIVE SHAPE REPEATER — PART25
One to64 transient copies of source geometry support per-copy XY translation,
rotation, scale, offset and start/end opacity. Copies do not duplicate stored
layers or change original paths. Scalar shapeRepeat channels and independent
named-group channels use the existing nested-time evaluator and motion.edit.
Expanded render bounds preserve repeated geometry through native camera/quad
projection and masks. Limits include2,048 aggregate repeated copies/frame,
16,384 local extent, bounded effective scale and existing canvas memory budgets.
This is native bounded motion graphics, not external AE/AEP/plugin compatibility.

Visual QA found the tools pane itself could overflow even when the outer page
fit. The desktop form was442px wide inside a248px pane. Scoped grid sizing and
wrapping now contain controls and text at320/390/768/1440px; the desktop form is
154px within that248px pane. The browser now measures actual controls and text
rectangles against the inspector. Repeater labels and guidance use plain names.

COMPOSITION AUDIO FADES — PART20/38
New zorifi-composition-audio.js validates existing audioFadeIn/Out fields and
evaluates ancestor envelopes using each containing composition's own clock.
It applies every fade once, without duplicating inherited gain or pan. Existing
root composition controls and reviewed Vanessa audio.fade share that validator.
Manual controls validate a draft before one snapshot, save on device and roll
back if persistence fails. Track/ancestor locks and account/project scope remain.
Children and original media stay editable. Runtime ancestry handles nested
constant-rate compositions; this does not add universal nested-target AI routing.

Live playback, MP4 audio, offline WAV and bounded Production Preflight now share
the ancestor envelope. Non-default container DSP is still rejected for offline
mix-down rather than silently omitted. Ducking-disabled preview/export gains
now use a short12ms smoothing time instead of the unrelated ducking-release
time, which previously smeared fades. Enabled ducking behavior is retained.
Native motion media now explicitly preload audio/video. Preview proof uses a
real Play gesture and a running AudioContext, not an autoplay assumption.

All prior offline mix budgets, source validation and cancellation guards remain.
Variable-rate/remapped offline audio, pitch-preserving time stretch, full buses,
sends/VCA/parallel chains and full-program LUFS/true-peak mastering remain gaps.
Underlying browser decode/render can finish after Stop; late output is discarded.

MUSIC PROVIDER SETTINGS FAILURE REPAIRED
The old shared metadata promise rejected before concurrent callers reached its
catch handler, producing an unhandled error on a genuine401 response. All callers
now share a guarded result with configured:false and the actual failure. Newest
request/source wins the cache; late old responses cannot overwrite it. The server
metadata fetch aborts after10s and offers retry. This does not fabricate successful
cloud generation or change authentication. Local tools remain usable when the
cloud settings endpoint is unavailable. Companion probing retains its own path.
