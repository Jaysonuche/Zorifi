NATIVE LINEAR AUDIO CROSSFADES — PART12/20
Audio → Audio crossfade selects an explicit outgoing/incoming root audio pair
on one unlocked typed audio layer. A0.01–30s overlap moves only the incoming clip
earlier, without extending either original source. Existing linear fade fields
drive preview, WAV and MP4. Source trims/constant rates, levels/pan and outer
fades stay intact. Incoming keys/spatial points/source-linked caption words shift
with its timeline clock. Later clips stay put; a gap can remain after the moved
incoming clip. The actual timing and this consequence are shown before applying.

Bounded pair metadata permits re-edit/reset using the original boundary, while
preserving unrelated names/levels/current animation/text edits. Changed timing,
source or fades invalidate the pair instead of silently overwriting later edits.
Locks, source overruns, third-clip/caption collisions, unsupported dependencies,
remaps/variable rates and malformed records refuse atomically. Graph traversal
is bounded at2000 layers/24 nested levels. One native snapshot/save per operation;
failed persistence restores the original timeline and Undo/Redo. Manual controls
and reviewed Vanessa commands use the same implementation, with natural receipts.

This is a root-pair linear arrangement crossfade, not equal-power curves, automatic
source-handle extension, ripple editing or full DAW routing/Live Session. Reset
the pair before changing source notes/instruments or restoring an earlier source.
Native note protection can still be changed independently; source-changing edits
cannot silently strand the strict crossfade record.

LOCAL ASSET LINEAGE / SOURCE HISTORY — PART22/38
Media cards and selected-media Properties have Source history. The read-only
inspector shows recorded source type/native instrument, current/nested usages,
containing timeline clocks, levels/fades/transforms/keyed-property counts, valid
saved checkpoints, explicit parent links and recorded native-source restores.
Sensitive arbitrary metadata, URLs, API keys and provider prompt bodies are not
rendered. Checkpoint damage/project checks are applied before observations; the
checksum is damage detection, not proof of server ownership. The UI reads only
the current account's existing projectVersionKey namespace.

These are observed saved states and explicit source links, not a continuous log
of every edit or proof of copyright/creator attribution. Future native source edits
now record the actual previous asset ID. Existing reviewed background-plate parent
links are readable; missing/unrecorded ancestry is never invented. Inspection
bounds:2000 current assets/layers,24 composition nesting,20 checkpoints,10000
historical layers and8MiB per checkpoint. Parent display stops at24 links with an
explicit finding, so long legitimate native revision chains remain inspectable.

Earlier-source restore initially supports the same root native audio layer in
a valid retained checkpoint. Both the original PCM file and matching editable
native pattern must still be available in this project's library. It keeps the
current start/duration/source trim/rate, level/pan/fades/effects/title and current
composition note protection. It restores audio + musical pattern together. Source
remaps, incompatible duration/instrument, locks, linked captions/cutouts and active
crossfades refuse. No visual reconstruction, deleted-file recovery, cloud backup,
external source fetch or regeneration is attempted.

Retained bytes are decoded and checked before a synchronous edit. Limits are
64MiB encoded and128MiB decoded; decoded memory is checked after native decode.
Positive-note sources must contain non-silent finite samples. Account/project/
revision/library/record changes and Stop are checked after asynchronous work.
The decoder closes before commit. The source and editable notes save as one Undo;
storage failure restores original state/history/URLs. New URLs are managed and
replaced URLs released. Up to16 explicit restore events stay on the native clip.
Browser decode itself may finish after cancellation; late results are discarded.
